# @webship.co/workspace-openproject

OpenProject, the open-source project management software, for the [Webship Workspace](https://github.com/webship/workspace)
dashboard. It brings a builder that makes a real OpenProject site in containers (DDEV by default), its default accounts
and a sample project, the OpenProject step pack wired into the workspace's testing setup, and its work packages as work
items of the tracker family ([`@webship.co/workspace-tracker`](https://github.com/webship/workspace-tracker)): read one,
analyze it, and let the workspace's AI CLI work it on a branch, with a person in charge.

The builder, the provider, the tests and CI come with the first release, `1.0.0`.
